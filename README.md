## 🏆 Featured Work

### 🏘️ [Alerta Vecino](https://alertavecino.com.mx/)
Co-founded and architected the largest neighborhood-security network in México: **30,000+ users across 8 Spanish-speaking countries**, in production for 10+ years. Native Android & iOS apps, PHP/MySQL back-office and IoT integrations (satellite alarms, Bluetooth panic buttons, SonOff devices).

### 🏗️ [Permit Nexus](https://permitnexus.app/) · Beta
AI copilot for construction permitting that preps, cross-examines and routes permit applications. Serverless backend on AWS (Lambda, Cognito, DynamoDB) with **Claude on Bedrock**, plus the marketing site.

### 🚚 [Fronterra](https://fronterra.app/) · Beta
Helps Mexican exporters, US food importers and customs agents prepare what the FDA asks for, and watches official sources to alert them in time. Public site, authenticated app, serverless backend and internal admin.

### 🤖 [StudioEngine.ai](https://studioengine.ai/)
Generative AI image platform: web app + public API on AWS EC2 + Docker, supporting Stable Diffusion, Flux, upscaling and inpainting.

### 📰 [Código Guerrero](https://codigoguerrero.com/)
AI-powered tech newsletter for the Spanish-speaking community. Three serverless services orchestrate Claude end to end: scouting, classification, editorial curation and AI-drafted editions delivered by email.

### 🥊 [Fighter Foundry](https://fighterfoundry.com/) · Beta
Native iOS app for combat-sports training paired with IoT impact sensors: real-time strike data, AI technique analysis and gamification.
